## Сейчас

Активно работаю над двумя продуктами.

**[Blue Unicorn](https://blueunicorn.ru)** - капсулы одежды и персональный стиль. Каталог образов, разборы фигуры, формула стиля и закрытый fashion-канал.

**[DeployClaw](https://deployclaw.ru)** - выделенный VPS под персонального ИИ-агента. OpenClaw, Hermes или Codex на отдельном сервере, консоль на русском, без ssh и ручной админки.

## Skills для агентов

- **[2captcha](https://github.com/adinvadim/2captcha-cli)** - решение капчи из CLI через 2Captcha. Image, reCAPTCHA v2/v3, hCaptcha, Turnstile, FunCaptcha, GeeTest, когда агент упирается в защиту сайта.
- **[giveurl](https://github.com/adinvadim/giveurl)** - быстрая расшарка скриншотов, Markdown и HTML между серверами внутри агентской сессии. Файл, папка или localhost превращаются в URL без конфига.

## CLI для российских хостингов

Чтобы агент сам крутил домены, DNS и VPS на привычных RU-площадках:

- **[beget-cli](https://github.com/adinvadim/beget-cli)** - Beget: аккаунт, домены, DNS, почта, MySQL, сайты, бэкапы и Cloud VPS
- **[reg-ru-cli](https://github.com/adinvadim/reg-ru-cli)** - REG.RU: CloudVPS, S3, биллинг, поддержка
- **[nic-cli](https://github.com/adinvadim/nic-cli)** - NIC.RU / RU-CENTER: зоны и DNS-записи, commit/rollback, DNS-01
